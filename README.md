# MarketSim: Adaptive Agentic AI Marketing Mastery Platform

**MarketSim** is a first-of-its-kind, full-stack SaaS platform designed to disrupt digital marketing education. It bridges the gap between theory and execution by providing hands-on, risk-free simulations powered by an **Agentic AI Mentor**.

---

## 🚀 The Core Vision
Most marketing courses are passive. MarketSim is active. I architected this platform to allow users to build real campaigns, conduct technical SEO audits, and analyze data in a simulated environment where failure costs nothing and learning is accelerated by AI.

## 🧠 Key Technical Features

### 1. ZOOMi: The Agentic AI Mentor
*   **Orchestration:** Integrated **Gemini API** for core intelligence and **ElevenLabs** for sentiment-aware voice feedback.
*   **Adaptive Logic:** Built a custom engine that analyzes user performance data in real-time to dynamically modify workshop difficulty and content.
*   **Agent Mode:** Features a proactive "Agent Mode" toggle where the AI takes autonomous actions to guide the user through complex roadblocks.

### 2. Full-Stack SaaS Infrastructure
*   **Monetization:** Integrated **Stripe API** for secure, multi-tier subscription management and "Pro Beta" feature gating.
*   **User Lifecycle:** Built a comprehensive onboarding flow, interactive tutorials, and a professional user dashboard.
*   **Data Viz:** Real-time visualization of marketing KPIs (Conversion rates, SEO health, Revenue trends) using structured JSON schemas.

### 3. Professional Simulator Suite
*   **SEO Auditor:** Automated technical site scanning with AI-generated fix-it roadmaps.
*   **Ad Platform Emulator:** Realistic interfaces for Google Ads, Meta, and LinkedIn campaign creation.
*   **Persona Builder:** Generative engine for high-fidelity psychographic customer profiles.

---

## 🛠 Technical Stack
*   **Logic & AI:** Gemini API, OpenAI, Prompt Engineering.
*   **Automation:** n8n, Zapier, Webhook Orchestration.
*   **Voice:** ElevenLabs Voice Synthesis.
*   **Backend & Payments:** Stripe API, Supabase, Node.js.
*   **Frontend:** HTML5, CSS3, JavaScript (ES6+), Vite/Replit.
